# v4.2 概览流量口径与信号交互升级

日期：2026-10-26

## 1. 已用量口径修复

### 问题

旧版概览将 C2000 `cpedata/refresh` 返回的 `threshold_smds` 直接显示为“本月已用流量”。
真机返回该值为五十余 GB，而“接入终端”页面同一时间可信终端显示累计合计仅约 2.4 GB。
该字段与原厂“流量套餐阈值”页面语义相关，不能直接当作近期实际消耗。

### 新口径

- 套餐“已消耗”默认取“接入终端”页面所有可信终端的本机显示累计之和。
- 单台终端显示值 = 设备累计计数器 − 本机清零/手动基线。
- 终端轮询更新后，概览同步更新；默认刷新周期为 15 秒。
- 手动输入不同的已消耗值并保存后切换为“手动值”；点击“用终端值”恢复自动实时模式。
- 剩余流量与百分比仍由套餐总量减去当前已消耗值实时计算。

### 本地清零

概览“本地清零”现在执行以下可解释操作：

1. 将所有终端当前设备累计值保存为本机显示基线；
2. 重置整机上下行显示基线；
3. 清空本地流量历史；
4. 恢复“自动实时”模式；
5. 立即刷新界面，之后新流量继续增长。

该操作不调用设备 SIM 流量清零接口，不修改锁频、SIM、Wi-Fi 或网络配置。
终端页原有的设备侧流量清零入口保持不变，仍属于独立的真机写操作。

## 2. 概览视觉与交互

- 保留固定 4×2 布局，8 块磁贴在当前窗口高度内完整显示。
- 减小磁贴内边距与间距，并统一关键数值容器，避免大块留白和数字裁切。
- CPU、内存、温度改为三枚并排环形指标，均可悬停查看状态和说明。
- 月套餐、信号、流量统计、实时速率、设备资源等可视化均具备悬停或点击反馈。
- 接入终端页面数据更新时，概览自动汇总值同步刷新。

## 3. 信号分析页面

新增 `SignalAnalysisChart` 自绘控件：

- 上半区：RSRP 质量分区色带和真实采样曲线；
- 中部：RSRQ 趋势；
- 下部：SINR 趋势；
- 三段共用同一真实时间轴，缺失数据和断连区间保持空白；
- 鼠标移动时显示十字线、精确采样时间、RSRP/RSRQ/SINR、质量等级、连接状态、Band、PCI、ARFCN；
- 深色与日间主题分别使用主题资源绘制，已通过实际页面检查。

当前值同时以 RSRP、RSRQ、SINR、CQI 四枚可交互环形指标展示。
