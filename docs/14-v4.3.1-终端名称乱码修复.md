# v4.3.1 接入终端名称乱码修复

日期：2026-10-27

## 问题

C2000 Pro 的 `terminal_all.client[].hostname` 是普通 UTF-8 文本，而旧
NRadio 兼容接口的终端名称是十六进制编码。兼容层此前统一把两者交给
`HexText.DecodeName`，因此 C2000 返回的普通名称只要恰好包含足够多的
十六进制字符，就会被误当成 HEX 数据解码并显示为乱码。

## 修复

- `ClientEntry` 新增显式的明文名称通道 `NameText`。
- C2000 Pro 适配器将设备上报的 UTF-8 `hostname` 直接填入 `NameText`，不再经过
  十六进制解码。
- 旧 NRadio 接口仍保留原有 HEX 名称解码行为，不影响兼容设备。
- 增加中英文混合终端名 `OfflineClient-客厅` 的离线回归测试。

## 验证

- Release 构建：0 警告、0 错误。
- 离线协议与终端名称回归：全部通过。
