## 二、概览图表

### 2.1 信号趋势图悬停

- 鼠标进入绘图区并靠近曲线时，按时间轴找到最近采样点，绘制竖向十字线、数据点圆点与浮动提示。
- 提示显示完整时间（`yyyy-MM-dd HH:mm:ss`）与设备上报的 RSSI 原始值（dBm）。
- 提示框跟随鼠标，默认显示在右上方；空间不足时翻到左侧/下方，并夹在控件边界内。
- RSSI 缺失或超出合理 dBm 范围（-140～-20）时不绘制提示，也不补 0。
- 信号图图例明确标注“RSSI（设备上报，dBm）”，不把工程页的 RSRP/RSRQ/SINR 原始编码当成 dBm。

### 2.2 实时速率图上传/下载

- 下载：蓝色，图例 `● 下载 ↓`；上传：青色，图例 `● 上传 ↑`；颜色与 `B.Down` / `B.Up` 主题资源一致。
- 悬停时同一时间点同时显示下载和上传，单位由 `J.Rate` 给出（B/s、KB/s、MB/s…）。
- 底部图例带与坐标轴时间标签分开，避免文字互相覆盖。
- 采样点新增 `HasSpeed`：
  - 首次只建立计数器基线时为 `false`；
  - 设备累计计数器缺失或回绕时为 `false`；
  - 只有真实可计算的差分区间才为 `true`。
- 图表遇到无效点会断开线段，不插值、不补 0；有效点不足 2 个时显示“等待有效的速率采样”。

### 2.3 兼容性

- 仍使用 `Controls/TrendChart.cs` 自绘，无第三方依赖。
- 保留 `Points`、`Mode`、`Title` 依赖属性，XAML 调用方式不变。
- 深浅主题、磁贴缩放和紧凑尺寸（220×120）均增加渲染回归检查。

|---|---|---|---|
| 网络质量监测 | 高：可快速区分路由器、外网和检测能力问题 | 中低：使用系统 ICMP/TCP，无需服务 | **已实现** |
| 信号质量预警 | 高：修正原有重复弹窗，明确原始值口径 | 低 | **已实现** |

| 断连/终端异常提醒 | 中高：终端事件容易因轮询抖动误报 | 中高 | **断连已去抖；终端事件暂缓** |

### 3.1 网络质量监测

设置中心新增“网络质量检测（独立于设备接口）”卡片：

- 路由器/网关：同时探测管理地址的 TCP 端口与 ICMP；
- 外网：探测两个独立目标（`223.5.5.5`、`119.29.29.29`）的 TCP 443；
- 延迟与丢包：来自 ICMP 真实回包；
- 自动检测默认关闭；开启后固定每 5 分钟最多一次，不参与高频轮询。

状态判定：

| 状态 | 判定条件 |
|---|---|
| 正常 | 路由器可达，且至少一个外网目标获得 TCP/ICMP 响应 |
| 本机网络未连接 | 没有可用的非回环 IPv4 网卡 |
| 路由器不可达 | 操作系统明确返回 Host/Network Unreachable |
| 外网连接失败 | 路由器可达，两个独立外网目标均无响应（提示同时可能为端口被拦截） |
| 检测失败 | 超时、ICMP 被丢弃、权限或读取网卡失败等无法判定情况 |

TCP 拒绝（RST）会被视为“主机在线”；ICMP 全部被丢弃时显示“无法统计”，**不会算成 100% 丢包**。

### 3.2 信号质量预警

- 阈值使用设备原始 `signal_quality` 档位 0–5，可在设置中心配置 0–4。
- 连续 3 次采样 ≤ 阈值才提醒；持续异常每 30 分钟最多提醒一次。
- 连续 3 次回到阈值以上才发送“信号已恢复”。
- 字段缺失/解析失败时不改变状态，不发送弱信号或恢复提醒。
- RSSI 只作为设备上报值展示；工程页 RSRP/RSRQ/SINR 是基带原始编码，不参与阈值。

### 3.3 流量阈值提醒

- 支持“每日流量”和“每月流量”两种周期。
- 去重键为 `周期类型:周期键:阈值`，写入 `settings.json`，软件重启后同一周期不会重复提醒。
- 跨日/跨月自动生成新键，重新开始判断；修改阈值也会重新判断。
- 只使用 `TrafficHistory` 的真实本地采样，不补齐软件未运行期间的流量。
- 存在未采集时段时，通知明确写出“实际设备用量可能更高”。
- 清理本地历史时同步清除去重键，避免清空后仍被旧键压住。

### 3.4 CSV 导出

设置中心新增：

- “导出当前流量视图 CSV”：导出概览当前选中的当日/近七天/本月柱状数据；
- “导出终端清单 CSV（脱敏）”：读取设备当前 `client_list`，包含累计、本月、近 3 日流量；
- 原“导出脱敏诊断日志”继续保留，并额外隐藏地址、IPv4 与 MAC。

终端 CSV 的脱敏规则：

- 名称/主机名保留首尾字符；
- MAC 保留前两段与后两段；
- IPv4 最后一段替换为 `***`；
- 以 `= + - @` 开头的单元格加 `'` 前缀，避免 CSV 公式注入；
- 文件使用 UTF-8 BOM，便于 Excel 正确识别中文。

### 3.5 断连与终端事件

- 设备轮询单次超时只记录日志，等待下一轮复核；连续 2 次失败才判定断连并提醒。
- 恢复连接后沿用原有恢复提醒。
- 终端新增/离线事件本轮未实现：设备只返回当前在线列表，没有连接事件时间线。
  若直接比较 15 秒轮询结果，DHCP 续租、Wi-Fi 休眠、设备接口短暂缺项都会造成误报。
  下一步若要实现，需要至少 2–3 个设备刷新周期的确认窗口和本地事件表，本轮不贸然加入。
