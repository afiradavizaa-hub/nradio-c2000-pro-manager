# NRadio C2000 Pro 审计与能力矩阵

> 验证日期：2026-10-26  
> 目标地址：`http://192.168.66.1`  
> 设备：`C2000-515` / 主固件 `NROS-2.2.5.0.1`  
> 说明：密码、Cookie、会话值、IMSI/ICCID 等敏感信息未写入本文。

## 1. 原项目审计结论

原项目是单一 Marvell MiFi 协议实现：

- `RouterClient` 固定使用 HTTP Digest、`login.cgi`、`xml_action.cgi`。
- `RouterApi` 把 18 个只读接口和 12 组写载荷直接绑定 NRadio 字段。
- ViewModel 通过具体 `RouterApi` 调用设备，没有统一协议接口。
- 现有 UI、主题、磁贴、流量历史、日志、DPAPI、CSV、设置迁移可继续复用。
- 工程使用 Git 管理；构建依赖 .NET 10 SDK。
- 原始基线编译通过：0 警告、0 错误。

新设备与旧协议的核心差异：

| 项目 | NRadio | C2000 Pro |
|---|---|---|
| 登录 | HTTP Digest、`login.cgi` | `POST /cgi-bin/luci` 表单 + `sysauth` Cookie |
| 用户名 | 用户输入（历史默认 admin） | NROS 登录页固定 root |
| 读接口 | `xml_action.cgi` + `json_*_info` | 真实 JSON 状态路由 + LuCI CBI 页面嵌入数据 |
| 写接口 | JSON POST `xml_action.cgi` | CBI multipart 表单或页面自身调用的专用 JSON 路由 |
| 数据编码 | SSID/终端名为十六进制编码 | SSID/终端名为普通 UTF-8 文本 |
| 信号值 | 工程字段为基带编码 | RSRP dBm、RSRQ/SINR dB 直接提供 |
| 会话失效 | `UNAUTHORIZED` / `KICKOFF` | 403 或重新出现登录页 |

因此没有把 C2000 字段硬套进旧请求格式，而是新增独立适配器。

## 3. 已确认接口与字段

### 3.1 认证

`GET /cgi-bin/luci`：

- 未登录返回 403 登录页。
- 表单字段：`luci_username=root`、`luci_password`、`luci_channel`。
- 成功后 `Set-Cookie: sysauth=...; path=/cgi-bin/luci/`。

`POST /cgi-bin/luci`：

- 成功返回受保护页面并建立 Cookie 会话。
- 客户端随后必须用受保护 JSON 接口复核，不能只看登录 HTTP 200。

### 3.2 只读 JSON

`GET /cgi-bin/luci/nradio/status/runtime/wan,cpe_4`

- `global.uptime/cpu_percent/mem_percent/net_type`
- `terminal_all.count/client`
- `client[].mac/ipaddr/hostname/rssi/txbytes/rxbytes/assoctime`
- `lans[].proto/status/ipaddrs`
- `cpe[].model/revision/mode/status/band/pci/earfcn/cell/tac`
- `cpe[].rsrp/rsrq/sinr/CQI/DLBW`
- `cpe[].imei/imsi/iccid/simcount/simno/sim_isp/isp/apn`
- `cpe[].V4/V6.ipaddrs/dns`
- `cpe[].download/upload/device_traffic/sim_flow`
- `wlan.radio[].ifname/ssid/encryption/channel/frequency/sta/assoclist`
- `bat.percent/charging`（当前设备 `percent=-1`）

`GET /cgi-bin/luci/nradio/cellular/cpestatus/cellinfo`

- `result[].status`：同 cpe 字段
- `result[].uptime/up`

`POST /cgi-bin/luci/nradio/cellular/cpestatus/info`

- 请求：`model=wan0&sim_id=1&earfcn=1&sim=1`
- 返回：`cfg.nr/lte`、当前 `status`、`sim`、`sim_company`、`neighbour`

`POST /cgi-bin/luci/nradio/cellular/sms/list`

- 请求：`channel=wan0`
- 返回：`on/code/ready/smslist`

`GET /cgi-bin/luci/nradio/cellular/sms/unread`

- 每个接口返回 `iface/count/max/used`

### 3.3 专业版页面

以下页面为 200，并包含真实设备值：

- `/nradio/cellular/cpelock/model/wan0`：Band & Cell Lock
- `/nradio/cellular/switch/model/wan0`：SIM Switch
- `/nradio/cellular/cpecfg/model/wan0`：SIM/网络制式设置
- `/nradio/basic/wifi`：双频 Wi-Fi
- `/nradio/cellular/sms/model/wan0`：SMS
- `/nradioadv/network/cpedata`：SIM Mgt.
- `/nradioadv/network/dhcp`：DHCP
- `/nradioadv/network/diag`：Diagnostics
- `/nradioadv/network/lan`、`access`、`dmz`、`forwarding`、`upnp`、`ipv6`
- `/nradioadv/wireless/acl`：Wi-Fi ACL
- `/nradioadv/system/restart`、`reset`、`passwd`、`at`、`logread`

页面中的写表单必须保留原厂 `token` 和未修改字段。软件对 CBI 表单采用“载入当前完整字段 → 只改目标字段 → 提交 → 回读”的方式，避免把未提交字段重置为默认值。

## 4. 当前能力限制

1. C2000 JSON 接口没有终端月度/近 3 日计数器，不能从整机总量拆分。
2. 设备报告 `bat.percent=-1`，无线模块和主板温度不能替代电池状态。
3. SMS 当前返回 `on=0/ready=0`，因此当前 SIM 条件下不能宣称短信可发送。
4. 设备只提供 HTTP，没有 HTTPS 端口；不能关闭 TLS 校验绕过问题。
5. 锁频/切卡/Wi-Fi 修改可能中断管理链路，写后回读是成功判定的必要条件。
6. 当前没有可信固件包和恢复方案，固件升级保持关闭。
