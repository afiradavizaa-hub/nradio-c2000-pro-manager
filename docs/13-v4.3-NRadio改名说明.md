# v4.3 NRadio 命名升级

日期：2026-10-26

## 修改范围

仅在独立的 NRadio C2000 Pro 项目中执行品牌重命名，原版项目保持不变。

- 产品名：`NRadio C2000 Pro 高级管理器`
- 程序集：`NRadioManager.dll`
- 可执行文件：`NRadioManager.exe`
- 根命名空间：`NRadioManager`
- 源码目录：`src\NRadioManager`
- 测试目录：`tests\NRadioManager.SelfTest`
- 用户数据目录：`%APPDATA%\NRadioManager`
- 数据隔离环境变量：`NRADIO_DATA_DIR`
- 测试凭据环境变量：`NRADIO_TEST_PASSWORD`

原设备的兼容适配器已改名为 `NRadioLegacyAdapter`，设备类型为
`DeviceKind.NRadioLegacy`，协议行为保持不变。

修改前已将旧版本程序和源码归档到工作区，并把原用户设置、流量历史和信号历史复制到新的
`%APPDATA%\NRadioManager`，因此本次改名不会要求重新录入设备设置。

## 验证

- 项目内源码、文档和文件名不再包含旧品牌名称。
- Release 构建：0 警告、0 错误。
- 离线协议测试：通过。
- 离线 UI 自检：`RESULT: OK`。
- 用户数据迁移：设置、流量历史、信号历史均已复制。
